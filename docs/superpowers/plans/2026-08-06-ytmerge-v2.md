# ytmerge v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace ytmerge's hand-rolled YouTube scraper with a yt-dlp subprocess engine that outputs, per video, an mp4 **and** a transcript text document (full metadata header + `[mm:ss]` timestamps), fed from a links file, clipboard, args, or stdin.

**Architecture:** The existing C++20 binary stays the orchestrator (URL extraction, worker pool, cache, clipboard). All YouTube interaction moves to two yt-dlp invocations per video: a fast metadata+subtitles pass (`--skip-download`), then a download pass reusing the fetched metadata via `--load-info-json`. New pure headers (`transcript.hpp`, `doc.hpp`, `ytdlp.hpp`, `deps.hpp`, `cli.hpp`) are unit-tested with doctest; `proc.hpp` wraps cross-platform subprocess spawning.

**Tech Stack:** C++20, libcurl (only for downloading the yt-dlp binary), nlohmann/json, doctest, yt-dlp (runtime dependency, auto-fetched), ffmpeg (optional, located on PATH).

**Spec:** `docs/superpowers/specs/2026-08-05-ytmerge-v2-design.md`

## Global Constraints

- C++20, header-only modules under `src/`, tests in `tests/` using the vendored `tests/doctest.h`.
- Build: `make` (app), `make test` (tests) from repo root in an MSYS2 UCRT64 shell on Windows.
- Video format selection verbatim from spec: `bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best`; single-file fallback when ffmpeg absent: `best[ext=mp4]/best`.
- Subtitle langs: `en.*,en`, format `json3`. Manual subs preferred over auto (yt-dlp orders this via `--write-subs --write-auto-subs`).
- Default output dir: `./downloaded`. Default workers: 4. Cache TTL: 7 days (unchanged).
- Update check: at most once per 24 h, **after** the batch, never blocking startup. `--update` forces it.
- Per-video isolation: one failure never aborts the batch.
- Commits: no Claude attribution trailers.
- New pure code goes in new headers, NOT into `core.hpp` (which keeps only what v1 tests already cover minus dead scraper code).

// transcript.hpp — pure json3-subtitle → timestamped-transcript logic.
// No I/O, no network; unit-tested in tests/test_v2.cpp.

#pragma once

#include <cstdio>
#include <string>
#include <vector>

#include "core.hpp"

namespace transcript {

struct Cue {
    double      start_s = 0.0;
    std::string text;
};

struct Chapter {
    double      start_s = 0.0;
    std::string title;
};

// Parse yt-dlp's json3 subtitle format: {"events":[{"tStartMs":N,"segs":[{"utf8":...}]}]}.
// Styling-only events (no segs), empty/whitespace cues, and consecutive
// duplicates (auto-caption rolling windows) are dropped.
inline std::vector<Cue> parse_json3_cues(const core::json& doc) {
    std::vector<Cue> cues;
    if (!doc.contains("events") || !doc["events"].is_array()) return cues;
    for (const auto& ev : doc["events"]) {
        if (!ev.contains("segs") || !ev["segs"].is_array()) continue;
        if (!ev.contains("tStartMs") || !ev["tStartMs"].is_number()) continue;
        std::string raw;
        for (const auto& seg : ev["segs"]) {
            if (seg.contains("utf8") && seg["utf8"].is_string())
                raw += seg["utf8"].get<std::string>();
        }
        for (char& c : raw)
            if (c == '\n' || c == '\t' || c == '\r') c = ' ';
        std::string text;
        bool prev_space = false;
        for (char c : raw) {
            if (c == ' ') {
                if (!prev_space && !text.empty()) text += ' ';
                prev_space = true;
            } else {
                text += c;
                prev_space = false;
            }
        }
        while (!text.empty() && text.back() == ' ') text.pop_back();
        if (text.empty()) continue;
        if (!cues.empty() && cues.back().text == text) continue;
        cues.push_back({ev["tStartMs"].get<double>() / 1000.0, std::move(text)});
    }
    return cues;
}

}  // namespace transcript
```

// "[m:ss]" below one hour, "[h:mm:ss]" at or above.
inline std::string format_timestamp(double seconds) {
    const long long s = static_cast<long long>(seconds);
    const long long h = s / 3600, m = (s % 3600) / 60, sec = s % 60;
    char buf[32];
    if (h > 0) std::snprintf(buf, sizeof buf, "[%lld:%02lld:%02lld]", h, m, sec);
    else       std::snprintf(buf, sizeof buf, "[%lld:%02lld]", m, sec);
    return buf;
}

// Cues joined into paragraphs. A new paragraph (blank line + timestamp) starts
// at every chapter boundary and whenever paragraph_interval_s seconds of
// speech have accumulated since the current paragraph began.
inline std::string render_transcript(const std::vector<Cue>& cues,
                                     const std::vector<Chapter>& chapters,
                                     double paragraph_interval_s = 45.0) {
    std::string out;
    size_t next_chapter = 0;
    double para_start   = 0.0;
    bool   first        = true;
    for (const auto& c : cues) {
        bool brk = first;
        if (!first && c.start_s - para_start >= paragraph_interval_s) brk = true;
        while (next_chapter < chapters.size() &&
               c.start_s >= chapters[next_chapter].start_s - 0.001) {
            if (!first) brk = true;
            ++next_chapter;
        }
        if (brk || first) {
            if (!first) out += "\n\n";
            out += format_timestamp(c.start_s);
            out += ' ';
            para_start = c.start_s;
            first = false;
        } else {
            out += ' ';
        }
        out += c.text;
    }
    return out;
}
```

// doc.hpp — video metadata model + transcript-document composition. Pure.

#pragma once

#include <cstdio>
#include <sstream>
#include <string>
#include <vector>

#include "core.hpp"
#include "transcript.hpp"

namespace doc {

struct VideoMeta {
    std::string id, title, channel, upload_date, description;
    long long   duration_s = 0, view_count = -1, like_count = -1;
    std::vector<std::string>         tags;
    std::vector<transcript::Chapter> chapters;
};

// nlohmann's .value() throws on present-but-null keys; these helpers don't.
inline std::string jstr(const core::json& j, const char* k) {
    return (j.contains(k) && j[k].is_string()) ? j[k].get<std::string>() : std::string();
}
inline long long jint(const core::json& j, const char* k, long long def) {
    return (j.contains(k) && j[k].is_number()) ? j[k].get<long long>() : def;
}

inline VideoMeta parse_info_json(const core::json& info) {
    VideoMeta m;
    m.id      = jstr(info, "id");
    m.title   = jstr(info, "title");
    m.channel = jstr(info, "channel");
    if (m.channel.empty()) m.channel = jstr(info, "uploader");
    const std::string d = jstr(info, "upload_date");  // "YYYYMMDD"
    if (d.size() == 8)
        m.upload_date = d.substr(0, 4) + "-" + d.substr(4, 2) + "-" + d.substr(6, 2);
    m.duration_s  = jint(info, "duration", 0);
    m.view_count  = jint(info, "view_count", -1);
    m.like_count  = jint(info, "like_count", -1);
    m.description = jstr(info, "description");
    if (info.contains("tags") && info["tags"].is_array())
        for (const auto& t : info["tags"])
            if (t.is_string()) m.tags.push_back(t.get<std::string>());
    if (info.contains("chapters") && info["chapters"].is_array())
        for (const auto& c : info["chapters"]) {
            transcript::Chapter ch;
            ch.start_s = (c.contains("start_time") && c["start_time"].is_number())
                             ? c["start_time"].get<double>() : 0.0;
            ch.title   = jstr(c, "title");
            m.chapters.push_back(std::move(ch));
        }
    return m;
}

inline std::string format_duration(long long s) {
    const long long h = s / 3600, m = (s % 3600) / 60, sec = s % 60;
    char buf[32];
    if (h > 0) std::snprintf(buf, sizeof buf, "%lld:%02lld:%02lld", h, m, sec);
    else       std::snprintf(buf, sizeof buf, "%lld:%02lld", m, sec);
    return buf;
}

}  // namespace doc
```

// The per-video text document: 80-char '=' divider, aligned header fields,
// blank line, transcript body. Format is spec'd in the v2 design doc.
inline std::string compose_document(const VideoMeta& m,
                                    const std::string& transcript_text) {
    static const std::string DIV(80, '=');
    std::ostringstream o;
    o << DIV << '\n'
      << "TITLE:    " << m.title << '\n'
      << "CHANNEL:  " << m.channel << '\n';
    if (!m.upload_date.empty()) o << "DATE:     " << m.upload_date << '\n';
    if (m.duration_s > 0)       o << "DURATION: " << format_duration(m.duration_s) << '\n';
    if (m.view_count >= 0) {
        o << "VIEWS:    " << m.view_count;
        if (m.like_count >= 0) o << "    LIKES: " << m.like_count;
        o << '\n';
    }
    o << "URL:      https://www.youtube.com/watch?v=" << m.id << '\n';
    if (!m.tags.empty()) {
        o << "TAGS:     ";
        for (size_t i = 0; i < m.tags.size(); ++i) {
            if (i) o << ", ";
            o << m.tags[i];
        }
        o << '\n';
    }
    if (!m.chapters.empty()) {
        o << "CHAPTERS: ";
        for (size_t i = 0; i < m.chapters.size(); ++i) {
            if (i) o << " | ";
            o << transcript::format_timestamp(m.chapters[i].start_s)
              << ' ' << m.chapters[i].title;
        }
        o << '\n';
    }
    if (!m.description.empty())
        o << "\nDESCRIPTION:\n" << m.description << '\n';
    o << DIV << "\n\n";
    o << (transcript_text.empty() ? "(no transcript available)" : transcript_text)
      << '\n';
    return o.str();
}

// Recover the title from a composed document (used to name .txt files
// restored from cache). Returns "" if no TITLE line is present.
inline std::string extract_title(const std::string& document) {
    const std::string key = "TITLE:    ";
    size_t pos = document.find(key);
    if (pos == std::string::npos) return "";
    pos += key.size();
    size_t end = document.find('\n', pos);
    if (end == std::string::npos) end = document.size();
    return document.substr(pos, end - pos);
}
```

// classification, filename sanitization. No process spawning here (proc.hpp).

#pragma once

#include <string>
#include <vector>

namespace ytdlp {

enum class Err {
    None,
    IpBlocked,    // HTTP 429
    Unavailable,  // private / deleted / geo-blocked / bad URL
    Network,      // anything else nonzero-exit
    Timeout,      // proc-level timeout (set by caller, not classify_stderr)
    NoYtdlp,      // binary missing and download failed (set by caller)
    ParseFailed,  // info.json / json3 unreadable (set by caller)
};

inline const char* error_label(Err e) {
    switch (e) {
        case Err::None:        return "ok";
        case Err::IpBlocked:   return "ip blocked (429)";
        case Err::Unavailable: return "video unavailable";
        case Err::Network:     return "network error";
        case Err::Timeout:     return "timed out";
        case Err::NoYtdlp:     return "yt-dlp missing";
        case Err::ParseFailed: return "parse failed";
    }
    return "unknown";
}

inline Err classify_stderr(const std::string& e) {
    auto has = [&](const char* s) { return e.find(s) != std::string::npos; };
    if (has("HTTP Error 429") || has("Too Many Requests")) return Err::IpBlocked;
    if (has("Private video") || has("Video unavailable") ||
        has("This video is unavailable") || has("members-only") ||
        has("removed by the uploader") || has("is not a valid URL") ||
        has("Unsupported URL") || has("not available in your country"))
        return Err::Unavailable;
    return Err::Network;
}

// For naming .txt docs when there is no mp4 path to mirror (--no-video).
// Mirrors yt-dlp --windows-filenames closely enough for standalone docs.
inline std::string sanitize_filename(std::string s) {
    static const std::string bad = "<>:\"/\\|?*";
    for (char& c : s)
        if (bad.find(c) != std::string::npos || static_cast<unsigned char>(c) < 32)
            c = '_';
    while (!s.empty() && (s.back() == ' ' || s.back() == '.')) s.pop_back();
    if (s.empty()) s = "untitled";
    return s;
}

inline const char* FORMAT_MERGED =
    "bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best";
inline const char* FORMAT_SINGLE = "best[ext=mp4]/best";

// Produces <workdir>/<id>.info.json and <workdir>/<id>.<lang>.json3.
inline std::vector<std::string> metadata_cmd(const std::string& ytdlp_path,
                                             const std::string& video_id,
                                             const std::string& workdir,
                                             const std::string& proxy) {

        "--no-playlist", "--no-progress", "--no-warnings", "--skip-download",

        "--sub-langs", "en.*,en", "--sub-format", "json3",

    };

}

// (no second webpage fetch); falls back to the URL when info_json_path is "".
// Prints the final media file path on stdout (last line).
inline std::vector<std::string> download_cmd(const std::string& ytdlp_path,
                                             const std::string& video_id,
                                             const std::string& info_json_path,
                                             const std::string& outdir,
                                             const std::string& fmt,
                                             bool audio_only,
                                             const std::string& audio_format,
                                             const std::string& proxy) {
    std::vector<std::string> c = {ytdlp_path};
    if (!info_json_path.empty()) {
        c.push_back("--load-info-json");
        c.push_back(info_json_path);
    } else {
        c.push_back("https://www.youtube.com/watch?v=" + video_id);
    }
    c.insert(c.end(), {
        "--no-playlist", "--no-progress", "--no-warnings",
        "--windows-filenames", "--no-overwrites",
        "--paths", outdir, "--output", "%(title)s.%(ext)s",
        "--no-simulate", "--print", "after_move:filepath",
    });
    if (audio_only) {
        c.push_back("--extract-audio");
        if (!audio_format.empty())
            c.insert(c.end(), {"--audio-format", audio_format, "--audio-quality", "0"});
    } else {
        c.insert(c.end(), {"--format", fmt});
    }
    if (!proxy.empty()) { c.push_back("--proxy"); c.push_back(proxy); }
    return c;
}

// proc.hpp — spawn a process with argv semantics (no shell), capture
// stdout/stderr via temp files (immune to pipe-buffer deadlocks), enforce a
// wall-clock timeout. Win32 + POSIX.

#pragma once

#if defined(_WIN32) && !defined(NOMINMAX)
  #define NOMINMAX
#endif

#include <atomic>
#include <chrono>
#include <filesystem>
#include <fstream>
#include <sstream>
#include <string>
#include <thread>
#include <vector>

#if defined(_WIN32)
  #include <windows.h>
#else
  #include <fcntl.h>
  #include <signal.h>
  #include <sys/wait.h>
  #include <unistd.h>
#endif

namespace proc {

struct Result {
    int         exit_code = -1;
    bool        timed_out = false;
    std::string out, err;
};

namespace detail {

inline std::string slurp_and_remove(const std::filesystem::path& p) {
    std::string s;
    {
        std::ifstream f(p, std::ios::binary);
        if (f) {
            std::ostringstream ss;
            ss << f.rdbuf();
            s = ss.str();
        }
    }
    std::error_code ec;
    std::filesystem::remove(p, ec);
    return s;
}

inline std::filesystem::path temp_base() {
    static std::atomic<unsigned> seq{0};
#if defined(_WIN32)
    const unsigned long pid = GetCurrentProcessId();
#else
    const unsigned long pid = static_cast<unsigned long>(getpid());
#endif
    std::error_code ec;
    auto dir = std::filesystem::temp_directory_path(ec);
    if (ec) dir = ".";
    return dir / ("ytmerge_p" + std::to_string(pid) + "_" + std::to_string(seq++));
}

#if defined(_WIN32)
inline std::wstring widen(const std::string& s) {
    if (s.empty()) return {};
    int n = MultiByteToWideChar(CP_UTF8, 0, s.data(), (int)s.size(), nullptr, 0);
    std::wstring w(n, L'\0');
    MultiByteToWideChar(CP_UTF8, 0, s.data(), (int)s.size(), w.data(), n);
    return w;
}

// Windows command-line quoting per the MSVCRT parsing rules.
inline std::wstring quote_arg(const std::wstring& a) {
    if (!a.empty() && a.find_first_of(L" \t\"") == std::wstring::npos) return a;
    std::wstring out = L"\"";
    size_t bs = 0;
    for (wchar_t c : a) {
        if (c == L'\\') { ++bs; continue; }
        if (c == L'"') {
            out.append(bs * 2 + 1, L'\\');
            out += L'"';
            bs = 0;
        } else {
            out.append(bs, L'\\');
            out += c;
            bs = 0;
        }
    }
    out.append(bs * 2, L'\\');
    out += L'"';
    return out;
}
#endif

}  // namespace detail

inline Result run(const std::vector<std::string>& argv, int timeout_s = 1800) {
    Result r;
    if (argv.empty()) return r;
    namespace fs = std::filesystem;
    const fs::path base  = detail::temp_base();
    const fs::path out_p = base.string() + ".out";
    const fs::path err_p = base.string() + ".err";

#if defined(_WIN32)
    SECURITY_ATTRIBUTES sa{sizeof(sa), nullptr, TRUE};
    HANDLE hOut = CreateFileW(out_p.wstring().c_str(), GENERIC_WRITE,
                              FILE_SHARE_READ, &sa, CREATE_ALWAYS,
                              FILE_ATTRIBUTE_NORMAL, nullptr);
    HANDLE hErr = CreateFileW(err_p.wstring().c_str(), GENERIC_WRITE,
                              FILE_SHARE_READ, &sa, CREATE_ALWAYS,
                              FILE_ATTRIBUTE_NORMAL, nullptr);
    if (hOut == INVALID_HANDLE_VALUE || hErr == INVALID_HANDLE_VALUE) {
        if (hOut != INVALID_HANDLE_VALUE) CloseHandle(hOut);
        if (hErr != INVALID_HANDLE_VALUE) CloseHandle(hErr);
        return r;
    }
    std::wstring cmdline;
    for (size_t i = 0; i < argv.size(); ++i) {
        if (i) cmdline += L' ';
        cmdline += detail::quote_arg(detail::widen(argv[i]));
    }
    STARTUPINFOW si{};
    si.cb = sizeof(si);
    si.dwFlags    = STARTF_USESTDHANDLES;
    si.hStdInput  = GetStdHandle(STD_INPUT_HANDLE);
    si.hStdOutput = hOut;
    si.hStdError  = hErr;
    PROCESS_INFORMATION pi{};
    // CreateProcessW may modify the buffer; pass a mutable copy.
    std::vector<wchar_t> buf(cmdline.begin(), cmdline.end());
    buf.push_back(L'\0');
    BOOL ok = CreateProcessW(nullptr, buf.data(), nullptr, nullptr, TRUE,
                             CREATE_NO_WINDOW, nullptr, nullptr, &si, &pi);
    CloseHandle(hOut);
    CloseHandle(hErr);
    if (!ok) {
        r.exit_code = 127;
        r.err = "failed to launch: " + argv[0];
        std::error_code ec;
        fs::remove(out_p, ec);
        fs::remove(err_p, ec);
        return r;
    }
    DWORD wait = WaitForSingleObject(pi.hProcess,
                                     static_cast<DWORD>(timeout_s) * 1000u);
    if (wait == WAIT_TIMEOUT) {
        TerminateProcess(pi.hProcess, 1);
        WaitForSingleObject(pi.hProcess, 5000);
        r.timed_out = true;
    }
    DWORD code = 0;
    GetExitCodeProcess(pi.hProcess, &code);
    r.exit_code = static_cast<int>(code);
    CloseHandle(pi.hProcess);
    CloseHandle(pi.hThread);
#else
    int out_fd = ::open(out_p.c_str(), O_CREAT | O_WRONLY | O_TRUNC, 0600);
    int err_fd = ::open(err_p.c_str(), O_CREAT | O_WRONLY | O_TRUNC, 0600);
    if (out_fd < 0 || err_fd < 0) {
        if (out_fd >= 0) ::close(out_fd);
        if (err_fd >= 0) ::close(err_fd);
        return r;
    }
    pid_t pid = ::fork();
    if (pid == 0) {
        ::dup2(out_fd, 1);
        ::dup2(err_fd, 2);
        std::vector<char*> cargv;
        cargv.reserve(argv.size() + 1);
        for (const auto& s : argv) cargv.push_back(const_cast<char*>(s.c_str()));
        cargv.push_back(nullptr);
        ::execvp(cargv[0], cargv.data());
        _exit(127);
    }
    ::close(out_fd);
    ::close(err_fd);
    if (pid < 0) return r;
    int status = 0;
    const auto deadline = std::chrono::steady_clock::now()
                          + std::chrono::seconds(timeout_s);
    while (true) {
        pid_t w = ::waitpid(pid, &status, WNOHANG);
        if (w == pid) break;
        if (std::chrono::steady_clock::now() > deadline) {
            ::kill(pid, SIGKILL);
            ::waitpid(pid, &status, 0);
            r.timed_out = true;
            break;
        }
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
    r.exit_code = WIFEXITED(status) ? WEXITSTATUS(status) : -1;
#endif

    r.out = detail::slurp_and_remove(out_p);
    r.err = detail::slurp_and_remove(err_p);
    return r;
}

}  // namespace proc

#include <string>
#include <vector>

#include "core.hpp"

namespace deps {

inline std::filesystem::path bin_dir(core::GetEnvFn get_env = &core::default_getenv) {
    auto d = core::cache_dir(get_env);
    if (d.empty()) return {};
    return d / "bin";
}

inline const char* ytdlp_local_name() {

    return "yt-dlp.exe";
#else

inline std::string ytdlp_download_url() {
#if defined(_WIN32)
    const char* asset = "yt-dlp.exe";
#elif defined(__APPLE__)
    const char* asset = "yt-dlp_macos";
#else
    const char* asset = "yt-dlp_linux";   // standalone build, no system python needed
#endif
    return std::string("https://github.com/yt-dlp/yt-dlp/releases/latest/download/")
           + asset;

inline std::optional<std::filesystem::path>
find_on_path(const std::string& exe, core::GetEnvFn get_env = &core::default_getenv) {
    const char* path = get_env("PATH");
    if (!path) return std::nullopt;
#if defined(_WIN32)
    const char sep = ';';
    const std::vector<std::string> names = {exe + ".exe", exe};
#else
    const char sep = ':';
    const std::vector<std::string> names = {exe};
#endif
    const std::string p(path);
    size_t start = 0;
    while (start <= p.size()) {
        const size_t end = p.find(sep, start);
        const std::string dir =
            p.substr(start, end == std::string::npos ? std::string::npos : end - start);
        if (!dir.empty()) {
            for (const auto& n : names) {
                std::filesystem::path cand = std::filesystem::path(dir) / n;
                std::error_code ec;
                if (std::filesystem::is_regular_file(cand, ec)) return cand;
            }
        }

std::optional<fs::path> ensure_ytdlp() {
    if (auto p = deps::find_on_path("yt-dlp")) return p;
    const fs::path dir = deps::bin_dir();
    if (dir.empty()) return std::nullopt;
    const fs::path local = dir / deps::ytdlp_local_name();
    std::error_code ec;
    if (fs::is_regular_file(local, ec)) return local;

    std::cerr << "yt-dlp not found — downloading (one-time, ~15 MB)...\n";
    HttpClient http;
    auto resp = http.get(deps::ytdlp_download_url());
    if (resp.curl_code != CURLE_OK || resp.status / 100 != 2 || resp.body.empty()) {
        std::cerr << "error: could not download yt-dlp (HTTP "
                  << resp.status << ")\n";
        return std::nullopt;
    }
    fs::create_directories(dir, ec);
    {
        std::ofstream f(local, std::ios::trunc | std::ios::binary);
        if (!f) return std::nullopt;
        f.write(resp.body.data(),
                static_cast<std::streamsize>(resp.body.size()));
    }
#if !defined(_WIN32)
    fs::permissions(local,
        fs::perms::owner_all | fs::perms::group_read | fs::perms::group_exec |
        fs::perms::others_read | fs::perms::others_exec,
        fs::perm_options::replace, ec);
#endif
    std::cerr << "yt-dlp installed to " << local.string() << '\n';
    return local;
}

std::optional<fs::path> find_subs_file(const fs::path& workdir,

    for (const auto& e : fs::directory_iterator(workdir, ec)) {
        if (!e.is_regular_file()) continue;
        const std::string name = e.path().filename().string();
        if (name.rfind(video_id + ".", 0) == 0 &&
            name.size() > 6 && name.substr(name.size() - 6) == ".json3")
            return e.path();

VideoOutcome process_video(const std::string& ytdlp_path,

                           const cli::Args& args,
                           ProxyPool& pool,

    VideoOutcome out;
    const fs::path workdir = core::cache_dir() / "work";
    std::error_code ec;
    fs::create_directories(workdir, ec);

    // Phase 1: metadata + subs. Retry across proxies on 429 (v1 policy: one
    // attempt when there is no pool to rotate through).
    const int max_attempts = pool.empty() ? 1 : 3;
    proc::Result meta_run;
    std::string used_proxy;
    for (int attempt = 0; attempt < max_attempts; ++attempt) {
        used_proxy = pool.next();
        meta_run = proc::run(
            ytdlp::metadata_cmd(ytdlp_path, video_id, workdir.string(), used_proxy),

        const auto err = ytdlp::classify_stderr(meta_run.err);
        if (err == ytdlp::Err::IpBlocked) { pool.mark_blocked(used_proxy); continue; }
        out.error = err;
        return out;
    }
    if (meta_run.exit_code != 0) { out.error = ytdlp::Err::IpBlocked; return out; }

    const fs::path info_path = workdir / (video_id + ".info.json");

        if (!f) { out.error = ytdlp::Err::ParseFailed; return out; }
        json info;
        try { f >> info; }
        catch (...) { out.error = ytdlp::Err::ParseFailed; return out; }
        meta = doc::parse_info_json(info);
    }
    if (meta.id.empty()) meta.id = video_id;
    out.title = meta.title.empty() ? video_id : meta.title;

        fs::remove(*subs, ec);
    }
    out.document = doc::compose_document(meta, transcript_text);

    // Phase 2: media download (skipped by --no-video). Reuses phase-1 metadata.
    fs::path media_path;

                        1800);
                    if (dl.timed_out || dl.exit_code != 0)
                        slot.outcome.video_note = "video download failed";
                } else {
                    slot.outcome = process_video(ytdlp_path->string(), slot.id,
                                                 args, pool, fmt);
                    if (slot.outcome.error == ytdlp::Err::None && !args.no_cache)
                        cache_write_doc(slot.id, slot.outcome.document);
                }
                std::lock_guard l(log_mu);
                std::cerr << "  [" << (job->index + 1) << "/" << ids.size()
                          << "] " << slot.id;
                if (slot.outcome.error == ytdlp::Err::None) {
                    std::cerr << "  ok";
                    if (!slot.outcome.video_note.empty())
                        std::cerr << "  (" << slot.outcome.video_note << ")";
                    std::cerr << '\n';
                } else {
                    std::cerr << "  FAIL: "
                              << ytdlp::error_label(slot.outcome.error) << '\n';
                }
            }
        });
    }
    q.close();
    for (auto& t : workers) t.join();

    // Merged clipboard blob + summary, input order preserved.
    std::string blob;
    std::unordered_map<std::string, int> failures;
    int ok = 0;
    bool ip_blocked = false;
    for (const auto& slot : results) {
        if (slot.outcome.error != ytdlp::Err::None) {
            failures[ytdlp::error_label(slot.outcome.error)]++;
            if (slot.outcome.error == ytdlp::Err::IpBlocked) ip_blocked = true;
            continue;
        }
        if (!blob.empty()) blob += "\n\n";
        blob += slot.outcome.document;
        ++ok;
    }

    if (ok > 0) write_clipboard(blob);

    std::ostringstream summary;
    if (ids.empty())      summary << "update check only";
    else if (ok == 0)     summary << "all " << ids.size() << " failed";
    else                  summary << ok << "/" << ids.size() << " ok — files in "
                                  << args.out_dir << ", transcripts on clipboard";
    if (!failures.empty()) {
        summary << "  [";
        bool first = true;
        for (const auto& [label, n] : failures) {
            if (!first) summary << ", ";
            summary << n << " " << label;
            first = false;
        }
        summary << "]";
    }
    notify(summary.str());
    if (ip_blocked) {
        std::cerr <<
            "  hint: YouTube has rate-limited this IP. Either:\n"
            "    - switch network (phone hotspot, VPN, different wifi)\n"
            "    - wait a few hours\n"
            "    - re-run with --proxy URL or --proxy-list FILE\n";
    }

    // Daily (or forced) yt-dlp self-update — after the batch, never before.
    maybe_update_ytdlp(*ytdlp_path, args.do_update);

    curl_global_cleanup();
    return (ok > 0 || (update_only && ids.empty())) ? 0 : 1;
}

# ytmerge

Links in a text file → mp4s and AI-ready transcript documents out. One command.
